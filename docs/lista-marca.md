# WoodGames Studio · Lista de lo necesario para la identidad de marca

Objetivo: que la marca se vea igual en la web, los posts, el correo, las redes y dentro del juego.
Marca cada punto cuando esté decidido o entregado.

---

## 1. Base de marca (decidir primero)
- [ ] Misión: qué hace el estudio y para quién (una frase)
- [ ] Valores: 3–5 palabras que guíen las decisiones
- [ ] Personalidad y tono de voz: por ejemplo cercano, artesanal, con humor o épico
- [ ] Público objetivo: tipo de jugador, edad, plataformas
- [ ] Referentes visuales: estudios o juegos que gustan y que no gustan (ya salieron pixelarte.es e iukanet.com)
- [ ] Qué significa "Wood" en la marca: madera, artesanía, naturaleza, cercanía…
- [ ] Idiomas de comunicación: español, inglés o ambos

## 2. Logo
- [ ] Tipo de logo: solo texto, símbolo + texto o mascota
- [ ] Versión principal (horizontal)
- [ ] Versión vertical o apilada
- [ ] Símbolo o isotipo suelto (para avatar, favicon e icono de app)
- [ ] Versiones en color, en negro y en blanco (sobre fondo oscuro)
- [ ] Tamaño mínimo y zona de respeto alrededor
- [ ] Usos incorrectos (no deformar, no cambiar colores…)
- [ ] Animación del logo para la intro del juego y los vídeos (sí/no)
- [ ] Archivos: SVG, PNG con fondo transparente y PDF

## 3. Color
- [ ] Color principal (1)
- [ ] Colores secundarios (2–3)
- [ ] Neutros: fondos, textos, grises
- [ ] Colores de estado: éxito, error, aviso (web y juego)
- [ ] Códigos HEX, RGB y CMYK (para imprimir)
- [ ] Comprobar el contraste y la legibilidad (accesibilidad)
- [ ] Versión para modo oscuro

## 4. Tipografía
- [ ] Fuente para titulares
- [ ] Fuente para textos largos
- [ ] Fuente para el juego o pixel, si aplica
- [ ] Licencia que permita uso web, en el juego y comercial (Google Fonts u otra de pago)
- [ ] Jerarquía: tamaños y pesos de H1, H2, texto y botones
- [ ] Fuente de respaldo para el correo (Arial, Georgia…)

## 5. Elementos gráficos
- [ ] Estilo de ilustración: pixel art, vectorial o pintado a mano
- [ ] Iconografía: estilo y grosor de línea
- [ ] Texturas o patrones (por ejemplo, vetas de madera)
- [ ] Estilo de fotografía o capturas del juego
- [ ] Mascota o personaje de marca (sí/no)
- [ ] Esquinas redondeadas o rectas, sombras, bordes

## 6. Aplicaciones (plantillas)
- [ ] Posts para redes: cuadrado, vertical y stories
- [ ] Portadas y avatares de cada red
- [ ] Firma de correo
- [ ] Plantilla de newsletter o correo comercial
- [ ] Presentación (dossier o press kit)
- [ ] Tarjetas de visita y papelería (si se imprimirá)
- [ ] Miniaturas de YouTube y vídeos
- [ ] Material para ferias (roll-up, merchandising) si aplica

## 7. Web
- [ ] Dominio y plataforma (WordPress, Webflow, a medida…)
- [ ] Secciones: inicio, juegos, estudio, prensa, contacto
- [ ] Favicon y metadatos para compartir enlaces (imagen OG)
- [ ] Press kit descargable
- [ ] Textos legales: privacidad, cookies, aviso legal

## 8. Dentro del juego
- [ ] Splash screen o intro con el logo
- [ ] Interfaz: botones, menús y tipografía coherentes con la marca
- [ ] Créditos
- [ ] Iconos de tienda (Steam, móviles, consolas) en sus tamaños
- [ ] Cápsulas y capturas para las tiendas
- [ ] Decidir hasta dónde llega la marca del estudio y dónde empieza la de cada juego

## 9. Protección y cuentas
- [ ] Comprobar que el nombre está disponible (registros de marca, otros estudios)
- [ ] Registrar la marca (OEPM / EUIPO)
- [ ] Registrar el dominio o dominios
- [ ] Reservar el mismo usuario en todas las redes
- [ ] Correo corporativo con el dominio propio
- [ ] Guardar la propiedad de los archivos fuente y las licencias de fuentes e imágenes

## 10. Proceso
- [ ] Quién decide y quién aprueba
- [ ] Calendario y fecha de lanzamiento
- [ ] Presupuesto (diseñador externo o equipo interno)
- [ ] Dónde se guardan los archivos de marca (carpeta compartida)
- [ ] Manual de marca final, como documento de referencia
- [ ] Revisión periódica (por ejemplo, cada 6–12 meses)

---

## Orden recomendado
1. Base de marca → 2. Logo → 3. Color → 4. Tipografía → 5. Elementos gráficos → 9. Protección (en paralelo, cuanto antes) → 6, 7 y 8. Aplicaciones → 10. Manual final

## Lo que el equipo tiene que enviar
- Referentes visuales (lo que gusta y lo que no)
- Logo, si ya existe, o un brief para crearlo
- Colores elegidos o una dirección de color
- Tipografías elegidas o un estilo deseado
- Respuestas al bloque 1 (misión, valores, tono, público)
