# WoodGames Studio

WoodGames Studio es una desarrolladora de videojuegos nueva. Este repositorio reúne la identidad de marca y la web del estudio.

## Cómo trabajar aquí

- **No diseñes ni propongas marca por iniciativa propia.** El usuario va enviando el material (juegos, colores, tipografía, logo, ideas del cliente). Haz solo lo que pida de forma explícita y pregunta antes de crear algo nuevo.
- Responde en español.
- Al terminar una sesión, ofrece hacer commit y push para poder seguir desde otro equipo.

## Estado del proyecto

- **Fase actual:** decidir la base de la marca (nombre, logo, color, tipografía, elementos gráficos, aplicaciones, web, registro de marca). Aún no hay nada decidido.
- **Dos webs separadas:** una con el método del cliente y otra con el método propio del usuario. Comparten una base igual o parecida (marca y contenido) y se publican por separado para compararlas. Estructura (carpetas creadas, vacías):
  - `base/`: lo común a las dos webs
  - `web-cliente/`: método del cliente
  - `web-propuesta/`: método del usuario
- **`marca/`:** borrador de sistema de diseño que se hizo sin que se pidiera. Está apartado: no se usa como referencia salvo que el usuario lo diga. También está publicado como artefacto privado en https://claude.ai/artifact/NTbaXb51qJ4AeuJzy7W5vZ.
- **`docs/lista-marca.md`:** lista de decisiones de marca, con casillas para marcar lo decidido.
- **`bocetos/web-v0.1/`:** primeros bocetos de la web (inicio, demo jugable de Orbital, página de Orbital), publicados en el lienzo privado https://claude.ai/artifact/PYTGWDTfNDVD8T6Q1YeG6H. Son bocetos, no diseño final.
- **Primer juego: Orbital** (arcade 2D de gravedad para iOS/Android, en producción). Futuro: "Taller de antigüedades" (nombre provisional).
- **Referencias de webs que dio el usuario:** https://pixelarte.es/ y https://www.iukanet.com/
